Browser

This browser can't talk to serial ports.

The installer needs Web Serial: Chrome, Edge or another Chromium browser on a desktop computer. Or flash with esptool from the release's flash zip.

3. Install

The install failed:

The board's recovery firmware may still start; if not, reload this page and try again. Holding BOOT while pressing RESET puts the board in its download mode by hand.

3. Installed

BMDS is installed and the board is starting.

Next, plug in the monitor, keyboard, mouse and Ethernet, and put in an SD card (FAT32 or exFAT). A window on the desktop offers to install the standard set of programs from the network. Without a network, unzip the release's packages zip onto the card first: the window finds the packages there.
